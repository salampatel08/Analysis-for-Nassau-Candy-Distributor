# Factory-to-Customer Shipping Route Efficiency Analysis

## 📌 Project Overview
This project analyzes logistics data for **Nassau Candy Distributor**.  
It maps products to factories, defines factory-to-customer routes, and evaluates efficiency using:
- Average lead time
- Total shipments
- Lead time variability

The goal is to highlight fastest and slowest routes, identify bottlenecks, and provide clear visualizations for decision-making.

---

## ⚙️ Tools & Technologies
- **Python**: Pandas, NumPy for data processing
- **Visualization**: Matplotlib, Seaborn, Plotly,PowerBI
- **Dashboard**: Streamlit for interactive web app,PowerBI
- **Version Control**: Git & GitHub

---

## 📊 Key Features
- Factory mapping for each product  
- Route definition (Factory → Customer State)  
- Route summary with aggregated metrics  
- Leaderboards for Top 10 fastest and Bottom 10 slowest routes  
- Interactive dashboard for visualization
